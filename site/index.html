Decisions, not essays.

Winnow is powered by Jev, a decision model that returns typed answers instead of free-form text: a yes/no probability, a choice with probabilities, or a score on a rubric. It cannot write a sentence onto your screen.

Install in a minute.

Winnow is not on the Chrome Web Store yet. Load the latest release unpacked.

  1. 1

    Download the release

    Grab the latest zip from GitHub releases and unzip it.

  2. 2

    Load it in Chrome

    Open chrome://extensions, turn on Developer mode, click Load unpacked and pick the folder.

  3. 3

    Paste your Jev key

    The onboarding page opens. Paste a key, click Verify, and optionally type your reading goals.

Get a Jev key. Free to create at console.typesafe.ai. Usage costs roughly a tenth of a cent per Hacker News page; cached for seven days, so a reload is free.
